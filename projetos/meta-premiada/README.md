# Projeto Meta Premiada — Portal de Transparência para Polos

## 🎯 Objetivo

Implementar um sistema de visualização de metas e rankings para os polos da instituição, permitindo transparência total sobre o desempenho em campanhas de vendas através do Portal Comercial.

## 📋 Descrição do Projeto

**Período:** Fevereiro – Março 2022  
**Patrocinador:** Ricardo Grima (Diretoria de Mercado)  
**PM Responsável:** Claudiomir Paveukieviz  
**Status:** ✅ Concluído

### Contexto Estratégico

A Uniasselvi realiza campanhas de vendas/metas entre seus polos para impulsionar o crescimento da instituição. Porém, os polos não tinham acesso transparente às métricas de atingimento de metas e sua posição no ranking competitivo. Isso gerava baixa engajamento e falta de alinhamento com objetivos corporativos.

**Desafio:** Criar um sistema que permitisse aos polos visualizar em tempo real:
- Sua pontuação individual no programa de metas
- Seu posicionamento no ranking comparado a outros polos
- Histórico de campanhas anteriores

### Solução Implementada

Desenvolvemos um módulo no Portal Comercial que oferece:

✅ **Ranking/Metodologia de Cálculo** — Criação de tabelas de parametrização para definir critérios de pontuação  
✅ **Dashboard de Metas** — Tela visual para consulta de pontuação por critério e posicionamento geral  
✅ **Relatórios Analíticos** — Processamento de dados e exportação de informações por polo  
✅ **Parametrização Dinâmica** — Ferramenta administrativo para ajuste de regras e critérios  

### Escopo do Projeto

**Fazer:**
- Criação de rankeamento com metodologia clara
- Tabelas de parametrização e dados processados
- Tela de visualização de metas no Portal Comercial
- Ferramenta de cadastro e parametrização administrativo

**Não fazer:**
- Extração de dados manual pelos polos
- Visualização de informações entre polos (somente próprio polo)
